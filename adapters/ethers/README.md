# @d402/ethers

Ethers integration for [d402](https://github.com/programmaman/d402), including
provider-neutral adapter capabilities and an Ethers-backed client constructor.

```sh
npm install d402 @d402/ethers ethers
```

See the [adapter guide](https://github.com/programmaman/d402/blob/master/docs/adapters.md)
for setup and usage.
