# @d402/viem

Viem integration for [d402](https://github.com/programmaman/d402), including
provider-neutral adapter capabilities and a Viem-backed client constructor.

```sh
npm install d402 @d402/viem viem
```

See the [adapter guide](https://github.com/programmaman/d402/blob/master/docs/adapters.md)
for setup and usage.
